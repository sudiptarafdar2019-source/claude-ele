# Reel Studio: Explainer template (polished hand explainer)

New `explainer` template for Orbirise Reel Studio: flat-vector scenes, a real hand that points/taps/writes,
Sudip's photo for 1-2 reaction moments, and on-screen words that pop in exactly when spoken.
Drop these files over the matching paths in `reel-studio/` (full studio lives in project files:
social-media/video-templates/reel-studio). First reel: `reels/websiteleave.json` ("Why visitors leave your website").
